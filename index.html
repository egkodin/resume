Другие проекты

2026, код закрыт

OxiGram

Неофициальный клиент Telegram для macOS на Rust, в ранней разработке. Работает с Telegram API через TDLib, интерфейс собран на GPUI — фреймворке редактора Zed. Код разбит на 11 модулей, привязки к API генерируются из схемы TDLib, видео и голосовые сообщения обрабатываются через FFmpeg и Opus.

Rust, TDLib, GPUI, FFmpeg

2026

Taglet

Настольный редактор тегов MP3-файлов без webview: название, альбом, номера треков, обложка. Перед первой записью сохраняет резервную копию файла и предупреждает о несохранённых изменениях.

Rust
